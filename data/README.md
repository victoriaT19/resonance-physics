# Dataset

The Resonance dataset consists of physics Q&A pairs generated from arXiv papers.

## Generation Process

1. Papers are collected from 5 arXiv categories using the arXiv API
2. A question is generated for each paper using category-specific templates
3. The base Gemma 4 E2B-IT model generates a real response for each question
4. Samples with responses shorter than 15 words are discarded
5. The dataset is split 90/10 into train/eval

## Categories

| Category | Description |
|----------|-------------|
| `physics.optics` | Optics and wave phenomena |
| `astro-ph.GA` | Galactic astronomy |
| `astro-ph.SR` | Stellar and solar physics |
| `physics.class-ph` | Classical mechanics and wave theory |
| `physics.em-ph` | Electromagnetism |

## Format

Each sample is a JSONL record:

```json
{
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "question about physics concept"},
    {"role": "assistant", "content": "Level 1 intuition + Level 2 formal derivation"}
  ],
  "metadata": {
    "arxiv_id": "2401.12345",
    "title": "Paper title"
  }
}
```

## Size

| Split | Samples |
|-------|---------|
| Train | ~85 |
| Eval  | ~10 |

## Note on Quality

Dataset responses are generated by the base model (not human-annotated), which means quality is bounded by the base model's physics knowledge. The fine-tuning reinforces the two-level response structure and domain focus rather than adding new knowledge.
